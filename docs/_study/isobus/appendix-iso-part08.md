# ISO 11783-8: Power train messages 정리

::: info 이 문서에 대해
ISO 11783-8 표준 원문을 학습 목적으로 재구성한 <strong>비공식 요약·해설</strong>이다. 규범적 판단이 필요할 때는 반드시 원문 표준을 확인해야 한다.
:::

## 개요

ISO 11783-8(2006, 1판)은 ISOBUS 시리즈 중 <strong>파워트레인(power train) 관련 메시지</strong>를 다루는 파트다. 트랙터와 자주식(self-propelled) 작업기가 엔진·변속기 등 구동계를 모니터링하고 제어하는 데 필요한 메시지를 규정한다.

이 파트의 가장 큰 특징은 <strong>본문이 사실상 "참조 문서"라는 점</strong>이다. 파워트레인 파라미터와 파라미터 그룹을 자체적으로 새로 정의하지 않고, 트럭·버스 업계 표준인 <strong>SAE J1939/71 (Application Layer)</strong>의 정의를 그대로 가져다 쓰도록 지시한다. 본문 분량도 3페이지에 불과하며, 실제 메시지 목록·수치 정의는 모두 J1939/71 쪽에 있다.

:::info 왜 J1939를 참조하는가
ISO 11783은 CAN 2.0B 기반이며, 상당 부분이 SAE J1939 문서군을 토대로 만들어졌다. J1939 문서 자체가 트럭·버스뿐 아니라 건설·농업 장비에서도 쓸 수 있도록 공동 작업으로 정비되었기 때문에, J1939 사양을 만족하는 전자 유닛을 최소한의 변경으로 농림업 장비에 재사용할 수 있다. 특히 네트워크 관리 측면에서 ISO 11783-8은 SAE J1939/81과 조화(harmonized)되어 있다.
:::

## 문서 위치와 구성

ISO 11783 시리즈 전체는 농림업용 트랙터와 장착식·반장착식·견인식·자주식 작업기 사이의 직렬 제어·통신 데이터 네트워크를 규정한다. 그 안에서 Part 8은 <strong>트랙터와 자주식 작업기가 필요로 하는 메시지</strong>, 즉 구동계 영역을 담당한다. 작업기(implement) 쪽 애플리케이션 메시지는 Part 7이 담당하며, 두 파트의 관계가 이 문서의 핵심 규칙을 만든다.

본문 구성은 다음과 같다.

| 절 | 제목 | 내용 |
|---|---|---|
| 1 | Scope | 적용 범위 |
| 2 | Normative references | 필수 참조 문서 |
| 3 | Terms and definitions | 용어 (ISO 11783-1 준용) |
| 4 | Technical requirements | 기술 요구사항 (4.1~4.3) |
| — | Bibliography | 참고 문헌 |

## 1절 — 적용 범위 (Scope)

센서, 액추에이터, 제어 요소, 정보 저장·표시 장치 사이의 데이터 전송 방법과 형식을 표준화한다는 ISO 11783 공통 목적 아래, Part 8은 <strong>트랙터 및 자주식 작업기에 요구되는 메시지</strong>를 기술하는 범위를 갖는다. 견인되는 일반 작업기의 프로세스 데이터가 아니라, 차량 자체의 구동계 정보가 대상이다.

## 2절 — 필수 참조 문서

세 문서가 normative reference로 지정되어 있으며, 이 중 J1939/71이 실질적인 본체 역할을 한다.

| 문서 | 역할 |
|---|---|
| ISO 11783-1 | 시리즈 공통의 일반 표준. 용어·정의의 출처 |
| ISO 11783-7 | Implement messages application layer. 파라미터 정의 충돌 시 <strong>우선권</strong>을 가짐 |
| SAE J1939/71 | Application Layer. 파워트레인 파라미터·파라미터 그룹의 <strong>실제 정의 출처</strong> |

## 3절 — 용어와 정의

별도 정의 없이 ISO 11783-1의 용어·정의를 그대로 적용한다.

## 4절 — 기술 요구사항

### 4.1 General

이 메시지 세트의 목적은 트랙터 또는 자주식 작업기의 <strong>파워트레인 모니터링과 제어</strong>를 지원하는 것이다. 엔진 회전수·차속·변속 상태 같은 구동계 정보를 네트워크 상의 다른 ECU(예: Task Controller, Virtual Terminal, 작업기 ECU)가 받아 쓰거나, 반대로 구동계에 제어 요청을 보내는 시나리오를 포괄한다.

### 4.2 Message parameter definitions — 파라미터 정의 규칙

파워트레인 제어에 필요한 <strong>개별 파라미터(J1939 용어로 SPN에 해당하는 수준)</strong>의 정의는 SAE J1939/71을 참조한다. 단, 하나의 예외 규칙이 있다.

:::warning 충돌 시 우선순위 규칙
어떤 파라미터가 SAE J1939/71에도 정의되어 있고 ISO 11783-7에도 정의되어 있다면, <strong>ISO 11783-7의 파라미터 정의를 따라야 한다(shall)</strong>. 즉 농업 도메인에서 재정의된 것이 있으면 그것이 트럭·버스 정의를 이긴다.
:::

### 4.3 Message parameter group definitions — 파라미터 그룹 정의 규칙

<strong>파라미터 그룹(PGN 단위의 메시지)</strong>에 대해서도 4.2와 동일한 구조의 규칙을 둔다. 정의 출처는 SAE J1939/71이고, ISO 11783-7에 같은 파라미터 그룹이 정의되어 있으면 ISO 11783-7의 정의가 우선한다.

## 해설 — 이 파트를 어떻게 읽어야 하나

ISO 11783-8은 자체 콘텐츠가 거의 없는 대신, 다음과 같은 <strong>계층 관계를 확정하는 문서</strong>로 이해하면 된다.

| 계층 | 담당 |
|---|---|
| 파워트레인 메시지의 원본 정의 | SAE J1939/71 (PGN·SPN 카탈로그) |
| 농업 도메인 재정의가 있는 경우 | ISO 11783-7이 우선 |
| 그 사실을 규범으로 못 박는 문서 | ISO 11783-8 (본 파트) |

실무적 함의는 다음과 같다.

- ISOBUS 스택에서 파워트레인 메시지(예: Electronic Engine Controller, Wheel-based Speed 계열)를 구현할 때 필드 배치·스케일·범위는 J1939/71 문서를 직접 찾아봐야 한다. Part 8 본문에는 메시지 표가 없다.
- 같은 PGN·파라미터가 ISO 11783-7에 등장하면 반드시 11783-7 판본을 구현해야 한다. 트럭용 정의와 농업용 정의가 미세하게 다른 경우를 대비한 안전장치다.
- 결과적으로 J1939 호환 ECU(엔진·변속기 컨트롤러 등)를 농기계 네트워크에 큰 수정 없이 올릴 수 있게 되며, 이것이 이 파트가 존재하는 실질적 이유다.
