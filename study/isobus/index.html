ISOBUS 스터디

스터디 소개

ISOBUS(ISO 11783)는 트랙터와 작업기(트랙터에 달거나 끌고 다니는 농기계)가 서로 통신하는 방법을 정한 국제 표준이다. 제조사가 달라도 트랙터와 작업기가 함께 동작하도록, CAN(자동차와 농기계에서 널리 쓰는 통신 방식) 위에 SAE J1939(트럭·버스용으로 만든 통신 규칙)과 ISOBUS 규칙을 차례로 쌓아 올린 구조다.

이 스터디에서는 다음을 배운다.

  • CAN 통신의 원리: 전선 위의 신호부터 프레임, 중재, 에러 처리, CAN FD까지
  • SAE J1939: CAN 위에서 메시지 종류를 정하고, 장치 주소를 관리하고, 긴 데이터를 나눠 보내는 방법
  • ISOBUS 네트워크: 버스와 커넥터 구성, 트랙터 ECU(트랙터 쪽 정보를 버스에 내보내는 제어 장치), 트랙터-작업기 메시지, 네트워크 관리와 진단
  • Virtual Terminal(VT): 트랙터 화면 하나에 여러 작업기의 조작 화면을 띄우는 방법
  • Task Controller(TC): 작업을 기록하고, 위치에 맞춰 살포량과 섹션을 제어하는 방법
  • File Server와 Sequence Control: 버스 위의 공용 저장소, 반복 조작을 기록했다가 재생하는 기능

누구를 위한 글인가

CAN과 통신을 처음 접하는 사람을 위해 썼다. 비개발자도 따라올 수 있게 1장은 "기계끼리 왜 대화해야 하는가"에서 시작하고, 새 용어는 처음 나올 때 쉬운 말로 풀어 쓴다. 1장부터 순서대로 읽으면 앞 장에서 배운 것만으로 다음 장을 이해할 수 있게 짰다.

ISOBUS 장비를 다루는 실무자와 직접 구현하는 개발자도 함께 쓸 수 있게, 메시지의 바이트 배치와 타이밍 같은 세부는 지우지 않고 "(심화)" 절에 남겼다.

2026-10 개편

  • ISO 원문 대조 보충: ISO 11783 원문(Part 1, 3~14)과 대조해 메시지 바이트 배치, 타이밍, 상태 머신, 오류 코드 같은 구현 세부와 바이트 단위 예제, 확인 문제를 더했다. 원문과 어긋나던 서술도 함께 바로잡았다.
  • 초보자용 재구성: 22장이던 글을 57장으로 나눴다. 장마다 학습 목표, 먼저 읽을 장, 핵심 정리, 확인 문제를 두고, 구현할 때만 필요한 세부는 "(심화)" 절로 표시했다.
  • 용어 사전 팝업: 본문에서 점선 밑줄이 그어진 용어를 누르면 풀이가 뜬다.

읽는 법

모든 장은 같은 틀을 따른다. 처음에 학습 목표와 먼저 읽을 장이 나오고, 끝에 핵심 정리와 확인 문제가 있다. 제목 끝에 "(심화)"가 붙은 절은 직접 구현할 때 필요한 세부다. 처음 읽을 때는 건너뛰어도 흐름을 놓치지 않는다.

처음이라면: 입문 경로

아래 장만 순서대로 읽어도 ISOBUS의 큰 그림을 잡을 수 있다. 이 경로에서는 "(심화)" 절을 모두 건너뛴다. 빠진 장은 큰 그림을 잡은 뒤 필요할 때 펼쳐 보면 된다.

단계읽을 장얻는 것
1. 통신과 CAN1, 2, 3, 4, 5, 6장전선 위의 0과 1이 메시지 한 개가 되는 과정
2. J19398, 9, 10, 12, 13, 15장메시지 종류 번호(PGN), 장치 주소, 긴 데이터를 나눠 보내는 법
3. ISOBUS 큰 그림18, 20, 23, 26장ISOBUS의 구성, 트랙터가 알려 주는 기본 정보, Working Set(여러 ECU를 한 장치로 묶는 단위)
4. 주요 기능29, 32, 36장(VT), 41, 45, 48장(TC)화면을 띄우는 VT, 작업을 기록하고 제어하는 TC
5. 실습55장로그를 읽고 VT와 TC의 흐름을 따라가기

실무자라면: 장비를 연결하고 점검하는 사람

CAN 기초를 이미 안다면 J1939의 핵심 장(8, 9, 12, 13, 15장)을 빠르게 훑고 ISOBUS 장으로 넘어간다.

  • ISOBUS 네트워크 전체: 18~28장(구성, 트랙터 메시지, Working Set, 진단)
  • VT와 TC 연결: 29~31장, 40장(보조 입력), 41~45장
  • 실습: 55~57장
  • 현장에서 펼쳐 볼 부록: 흔한 실수와 트러블슈팅, PGN/SPN 주요 목록, DDI 주요 목록, AEF 기능 카테고리

직접 구현한다면: 제어 장치(ECU)나 VT·TC 클라이언트를 만드는 사람

1장부터 57장까지 "(심화)" 절을 포함해 모두 읽는다. 바이트 배치와 타이밍을 집중해서 다루는 장은 다음과 같다.

  • J1939: 11, 14, 16, 17장
  • ISOBUS 네트워크: 19, 21, 22, 24, 25장
  • VT: 30, 31, 33, 34, 35, 37, 38, 39, 40장
  • TC: 43, 46, 47, 49, 50장
  • File Server와 Sequence Control: 52, 54장
  • 파일 형식: 56, 57장

표준 문서의 구조대로 세부를 확인하고 싶으면 이 페이지 아래의 "ISO 11783 표준 정리" 부록을 함께 본다.

용어 사전 사용법

본문에서 점선 밑줄이 그어진 용어를 누르면 짧은 풀이가 팝업으로 뜬다. 밑줄은 절마다 그 용어가 처음 나오는 곳에만 그어진다. 팝업은 보조 수단이라, 본문도 용어가 처음 나올 때 풀어 쓴다. 전체 목록은 용어 사전에서 볼 수 있다.

학습 로드맵

57장을 아홉 묶음으로 나누면 아래 흐름이 된다. 바탕이 되는 통신(CAN, J1939)을 먼저 쌓고, ISOBUS 공통 규칙(네트워크 구성, 트랙터-작업기 메시지, 네트워크 관리)을 익힌 뒤, VT와 TC 같은 기능으로 갈라진다. File Server와 Sequence Control은 VT, TC와 같은 바탕 위에서 동작하는 기능이고, 마지막 실습에서 모두 합쳐 본다.

전체 목차

통신과 CAN 기초 (1~7장)

장제목한 줄 설명
1통신의 기초기계끼리 대화하는 이유와 디지털 신호, 직렬 통신, 버스, 프로토콜의 기본 개념
2CAN 통신 입문CAN이 무엇이고 어디에 쓰이는지, 다른 통신 방식과 무엇이 다른지
3CAN 물리 계층: 전선 위의 0과 1두 전선의 전압 차로 0과 1을 보내는 방법, 종단 저항, 통신 속도와 선 길이
4CAN 데이터 프레임CAN 메시지 한 개(프레임)를 이루는 칸들의 역할과 로그에서 프레임을 읽는 법
5CAN 중재와 우선순위여러 장치가 동시에 보낼 때 ID가 작은 메시지가 충돌 없이 먼저 나가는 원리
6CAN 에러 처리오류를 찾아내는 다섯 가지 방법, 에러 카운터, 고장 난 장치가 버스에서 빠지는 Bus Off
7CAN FD한 번에 더 많이, 더 빠르게 보내는 CAN FD의 구조와 기존 CAN, ISOBUS와의 관계

SAE J1939 (8~17장)

장제목한 줄 설명
8SAE J1939 입문CAN 위에 규칙을 더한 J1939의 역할과 29비트 ID에 담긴 정보
9J1939 메시지 구조: 29비트 ID, PGN, SPNID를 쪼개 메시지 종류(PGN)와 값 번호(SPN)를 읽고 실제 값으로 바꾸는 법
10요청과 응답: Request, ACK, Group function다른 장치에 데이터를 달라고 요청하고, 받았다는 확인을 돌려주는 메시지
11Request2, Transfer와 수신·응답 규칙확장된 요청 메시지와, 응답을 얼마나 빨리 해야 하는지 정한 시간 규칙
12주소와 NAME: 누가 보냈는지 알아보는 법1바이트 주소와 64비트 이름(NAME)으로 장치를 구별하는 방법
13주소 클레임: 주소를 정하는 절차전원을 켠 장치들이 겹치지 않게 주소를 차지하는 절차와 충돌 해결
14NAME 관리와 네트워크 초기화실행 중에 NAME을 바꾸는 명령, 주소 위반 처리, 전원을 켤 때의 초기화 순서
15Transport Protocol 기초: 8바이트보다 긴 데이터 보내기긴 데이터를 여러 프레임으로 나눠 보내는 두 방식, 모두에게 알리는 BAM과 1대1 연결인 CMDT
16TP 연결 규칙과 타이머TP 연결을 열고, 잠시 멈추고, 닫는 규칙과 타이머, 재전송
17Extended Transport Protocol: 1,785바이트보다 큰 데이터VT 화면 데이터처럼 아주 큰 데이터를 보내는 ETP와 4,000바이트 전송 예

ISOBUS 개요와 네트워크 (18~21장)

장제목한 줄 설명

19ISO 11783 Part 1: 네트워크 요구사항과 공통 서비스ISO 11783 전체가 따르는 네트워크 요구사항, 공통 서비스, 코드 데이터베이스
20ISOBUS 네트워크 구성: 버스, 커넥터, ECU트랙터와 작업기를 잇는 버스와 커넥터 구성, 주요 ECU의 역할
21네트워크 계층과 NIU: 버스와 버스를 잇는 장치두 버스를 연결하는 장치(NIU)가 메시지를 넘기거나 걸러 내는 방법

트랙터와 작업기 메시지 (22~25장)

장제목한 줄 설명
