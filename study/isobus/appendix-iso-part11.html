ISO 11783-11: Mobile data element dictionary 정리

이 문서에 대해

ISO 11783-11 표준 원문을 학습 목적으로 재구성한 비공식 요약·해설이다. 규범적 판단이 필요할 때는 반드시 원문 표준을 확인해야 한다.

개요

ISO 11783-11(2011, 2판)은 ISOBUS의 프로세스 데이터 식별자 사전을 다루는 파트다. ISO 11783-10(Task Controller)의 Process Data message로 주고받는 데이터 요소(data element)들에 대해, 각 요소를 식별하는 번호 체계와 정의 속성을 규정한다. 실무에서 흔히 말하는 DDI(Data Dictionary Identifier)가 바로 이 파트가 규정하는 식별자다.

이 파트의 결정적 특징은, 사전의 실제 내용(개별 DDI 목록)을 표준 문서 본문에 싣지 않고 온라인 데이터베이스로 외부화했다는 점이다. 본문은 3페이지에 불과하며, "Process Data message로 전송되는 가변 데이터는 ISOBUS Data Dictionary에 정의된 대로 따라야 한다"는 규범과 그 사전 엔트리가 갖춰야 할 속성 목록만 남긴다. 사전 자체는 isobus.net에서 관리된다.

표준의 온라인 외부화

농업 기계의 센서·작업 종류는 계속 늘어난다(파종량, 시비량, 수확량, 작업 폭…). 새 데이터 요소가 생길 때마다 ISO 표준 개정 절차(투표·출판)를 거치면 수 년이 걸린다. 그래서 이 파트는 식별자 체계의 "틀"만 표준으로 고정하고, 엔트리 추가·수정은 온라인 사전의 유지관리 절차로 돌렸다. 표준 문서는 안정성을, 온라인 DB는 확장 속도를 맡는 분업 구조다.

문서 위치와 구성

ISO 11783 시리즈 안에서 Part 11은 Part 10(Task Controller and management information system data interchange)과 짝을 이룬다. Part 10이 프로세스 데이터를 어떻게 주고받는지(메시지·프로토콜·Device Descriptor)를 정의한다면, Part 11은 그 안에 실리는 값이 무엇을 의미하는지(식별자와 의미·단위)를 정의한다.

2판(2011)은 1판(2007)의 minor revision으로, 1판을 대체한다. 본문 구성은 다음과 같다.

절제목내용
1Scope적용 범위
2Normative references필수 참조 문서 (온라인 사전 포함)
3Terms, definitions, symbols and abbreviated terms용어 (ISO 11783-1 준용)
4Technical requirements기술 요구사항 (4.1~4.2)
—Bibliography참고 문헌

1절 — 적용 범위 (Scope)

ISO 11783 공통의 목적(트랙터·작업기 간 데이터 전송의 방법·형식 표준화) 아래에서, Part 11의 범위는 ISO 11783-10에 정의된 Process Data message에 사용되는 데이터 요소의 식별자를 규정하는 것이다. 즉 통신 절차가 아니라 "데이터의 이름표"가 대상이다.

2절 — 필수 참조 문서

문서역할
ISO 11783-1시리즈 공통 일반 표준. 용어·정의·기호·약어의 출처
ISO 11783-10Process Data message가 정의된 파트. Part 11이 식별자를 공급하는 대상
ISOBUS Data Dictionary (http://www.isobus.net/)온라인 사전 자체가 normative reference로 지정됨

온라인 데이터베이스가 필수 참조 문서 목록에 오른 것이 이 파트의 핵심 장치다. 사전의 최신 내용이 곧 규범의 일부가 된다.

3절 — 용어와 정의

별도 정의 없이 ISO 11783-1의 용어·정의·기호·약어를 그대로 적용한다.

4절 — 기술 요구사항

4.1 General — 온라인 사전 준수 의무와 유지관리 주체

ISO 11783-10에 따라 Process Data message로 전송되는 가변 데이터는 ISOBUS Data Dictionary(isobus.net)에 정의된 대로 따라야 한다(shall). 임의로 만든 식별자나 사전과 다른 해석을 쓸 수 없다.

유지관리 기관(Maintenance Agency)

이 온라인 데이터베이스의 유지관리 책임은 VDMA(독일기계공업협회, German Engineering Federation)에 있다. VDMA는 ISO 기술관리이사회(ISO/TMB)가 지명한 공식 maintenance agency(MA)다. 즉 새 DDI의 등록·심사·발행은 ISO 개정 절차가 아니라 VDMA가 운영하는 사전 관리 절차를 거친다. 제조사가 새로운 프로세스 데이터가 필요하면 이 체계를 통해 DDI 신설을 신청하게 된다.

4.2 Process data element definitions — 사전 엔트리의 필수 속성

프로세스 데이터 요소 하나를 사전에 정의할 때는 다음 다섯 가지 속성을 갖추어야 한다.

속성의미
identification number데이터 요소의 식별 번호 (DDI)
definition그 데이터 요소가 무엇인지에 대한 정의
range값의 유효 범위
resolution값의 분해능(1비트가 나타내는 물리량 단위)
units물리 단위

이 다섯 속성이 갖춰져야 서로 다른 제조사의 Task Controller와 작업기 ECU가 같은 숫자를 같은 의미·같은 스케일로 해석할 수 있다.

해설 — DDI 체계가 실무에서 작동하는 방식

Part 11 본문은 짧지만, 이 파트가 고정해 놓은 틀 위에서 ISOBUS 프로세스 데이터 생태계 전체가 돌아간다.

  • 식별자 사용처: 작업기 ECU는 Part 10의 Device Descriptor Object Pool(DDOP)에서 자기 장치의 각 프로세스 값(예: 목표 살포량, 실제 작업 폭, 작업 상태)에 DDI를 붙여 Task Controller에 알린다. 이후 Process Data message에서는 이 DDI로 어떤 값인지 지목한다.
  • 상호운용성의 근거: range·resolution·units가 사전에 박제되어 있으므로, Task Controller는 처음 보는 장비라도 DDI만 보고 값을 올바른 물리량으로 환산·기록할 수 있다. 정밀농업에서 작업 기록(as-applied 데이터)이 제조사 경계를 넘어 호환되는 이유가 여기에 있다.
  • 확장 절차: 표준 개정 없이 VDMA의 MA 절차로 새 DDI가 계속 추가된다. 구현체 입장에서는 isobus.net의 최신 사전 익스포트를 주기적으로 반영하는 운영 습관이 필요하다.
  • Part 8과의 대비: Part 8이 파워트레인 메시지 정의를 SAE J1939/71이라는 외부 표준 문서에 위임했다면, Part 11은 프로세스 데이터 정의를 온라인 데이터베이스에 위임했다. 둘 다 "얇은 규범 + 외부 정의 소스"라는 같은 패턴이지만, 위임 대상의 성격이 다르다.
