참고 자료

스터디를 마친 뒤 더 깊이 파고들 수 있는 표준 문서와 공식 문서를 카테고리별로 모았다. 1차 출처는 언제나 표준 원문과 AWS 공식 문서이므로 그것부터 둔다. 본문에서 인용한 링크와 본문 작성에 쓴 사실 확인 자료의 링크만 실었다.

W3C 표준

  • WebRTC 1.0 (W3C) — RTCPeerConnection·RTCDataChannel 등 브라우저 API 명세. 현행 Recommendation이다.
  • WebRTC 표준 이력 (W3C) — Recommendation 발행·재발행 이력

IETF 표준과 RFC

연결 수립, 미디어, 보안, 데이터 채널, 기타 순서로 정리했다. 괄호의 장 링크는 본문에서 해당 RFC를 다룬 곳이다.

개요와 연결 수립

  • RFC 8825 - WebRTC Overview — WebRTC 프로토콜 묶음(RFC 8825~8835)의 개요
  • RFC 9429 - JSEP — Offer/Answer 기반 세션 수립 모델. 기존 RFC 8829를 대체한다.
  • RFC 8866 - SDP: Session Description Protocol — 세션 기술 형식인 SDP의 문법과 필드 (04장장)
  • RFC 9143 - Negotiating Media Multiplexing Using the Session Description Protocol (SDP) — BUNDLE로 여러 미디어를 하나의 전송에 다중화하는 협상 (04장장)
  • RFC 4787 - Network Address Translation (NAT) Behavioral Requirements for Unicast UDP — NAT 매핑·필터링 동작 분류 (05장장)
  • RFC 8489 - STUN — Binding 요청과 XOR-MAPPED-ADDRESS
  • RFC 8656 - TURN — 릴레이 할당·퍼미션·채널 바인딩
  • RFC 8445 - ICE — 후보 수집·우선순위·연결 확인 절차
  • RFC 8838 - Trickle ICE — 후보를 점진적으로 교환하는 방식
  • RFC 7675 - Session Traversal Utilities for NAT (STUN) Usage for Consent Freshness — 연결 후 주기적으로 송신 동의를 확인하는 Consent Freshness (06장장)
  • RFC 9725 - WHIP — HTTP 기반 WebRTC 인제스트 프로토콜
  • draft-ietf-wish-whep — WHEP 드래프트. 작성 시점 기준 아직 draft 단계다.

미디어

  • RFC 3550 - RTP: A Transport Protocol for Real-Time Applications — RTP·RTCP의 기본 정의 (08장장)
  • RFC 4585 - Extended RTP Profile for Real-time Transport Control Protocol (RTCP)-Based Feedback (RTP/AVPF) — NACK·PLI 같은 RTCP 피드백 메시지 (09장장)
  • RFC 8888 - RTP Control Protocol (RTCP) Feedback for Congestion Control — 혼잡 제어용 RTCP 피드백 형식 (09장장)
  • RFC 6184 - RTP Payload Format for H.264 Video — H.264 영상의 RTP 패킷화 방식 (08장장)
  • RFC 7742 - WebRTC Video Processing and Codec Requirements — WebRTC 필수 비디오 코덱 요구 사항 (08장장)
  • RFC 7874 - WebRTC Audio Codec and Processing Requirements — WebRTC 필수 오디오 코덱 요구 사항 (08장장)
  • draft-holmer-rmcat-transport-wide-cc-extensions-01 — transport-wide-cc RTP 헤더 확장(TWCC) 드래프트

보안

  • RFC 8827 - WebRTC Security Architecture — WebRTC 보안 모델과 위협 분석 (10장장)
  • RFC 3711 - The Secure Real-time Transport Protocol (SRTP) — RTP 미디어 암호화·인증 (10장장)
  • RFC 5764 - Datagram Transport Layer Security (DTLS) Extension to Establish Keys for the Secure Real-time Transport Protocol (SRTP) — DTLS 핸드셰이크로 SRTP 키를 교환하는 DTLS-SRTP (10장장)
  • RFC 7983 - Multiplexing Scheme Updates for Secure Real-time Transport Protocol (SRTP) Extension for Datagram Transport Layer Security (DTLS) — 한 포트에서 STUN·DTLS·SRTP를 구분하는 다중화 규칙 (10장장)
  • RFC 9605 - Secure Frame (SFrame): Lightweight Authenticated Encryption for Real-Time Media — SFU 구간에서도 유지되는 프레임 단위 종단간 암호화 (12장장)

데이터 채널

  • RFC 8831 - WebRTC Data Channels — 데이터 채널 전송 모델 (11장장)
  • RFC 8832 - WebRTC Data Channel Establishment Protocol — DCEP로 채널을 여는 절차 (11장장)
  • RFC 8261 - Datagram Transport Layer Security (DTLS) Encapsulation of SCTP Packets — DTLS 위에 SCTP를 싣는 방식 (11장장)
