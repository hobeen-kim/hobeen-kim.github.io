# 스터디 챕터 표준 포맷

모든 스터디 챕터는 아래 구조를 따른다. 집필 에이전트는 이 파일을 읽고 형식을 그대로 복제해 내용만 채운다.

골든 샘플(형식·깊이 기준): `docs/_study/webrtc/07-turn.md` (챕터), `docs/_study/webrtc/README.md` (소개 페이지). 단, 이 샘플에는 확인 문제가 없다 — 새 챕터는 아래 템플릿대로 넣는다.

## 템플릿

```markdown
---
title: "챕터 제목"
description: "한두 문장 설명"
date: YYYY-MM-DD
tags: [주제태그, 세부태그]
prev: /study/{slug}/{이전 파일명}
next: /study/{slug}/{다음 파일명}
---

- ICE 실패 로그를 보고 원인(방화벽·NAT·TURN 미설정)을 구분할 수 있다.
```

## 체크리스트

| 항목 | 규칙 | 이유 |
|------|------|------|
| frontmatter | title, description, date, tags, prev, next | prev/next가 페이지 하단 내비게이션을 만든다 |
| 첫 챕터 prev | `/study/{slug}/` (소개 페이지) | |
| 마지막 페이지 next | `false` | |
| `# 제목` | frontmatter 직후 h1 | `<Header />`는 옛 형식이다 |
| 학습 목표 | `::: info 학습 목표`, 2~4개, 관측 가능한 동사 | "이해한다/안다"는 달성 여부를 확인할 수 없다. "계산할 수 있다·비교할 수 있다·설계할 수 있다·진단할 수 있다"처럼 쓴다 |
| 절 | `## 1.` `## 2.` … 번호, 4~7개 | |
| 소제목 | `###` | |
| 핵심 정리 | `::: tip 핵심 정리`, 마지막 절 뒤 | |
| 확인 문제 | `::: details 확인 문제`, 1~2문제 + 답 가이드 | 접혀 있어 스포일러가 안 되고, 학습 목표와 1:1로 대응시키면 목표가 실제로 다뤄졌는지 점검된다. 낮은 단계 목표는 설명·비교형, 높은 단계는 설계·디버깅 시나리오형 |
| 다음 챕터 | `## 다음 챕터` + 산문 한 줄 링크 | 마지막 부록에는 없음 |
| 출처 | 수치·API·표준 상태 같은 핵심 주장 옆에 공식 문서 링크 | 본문에 링크가 없으면 참고 자료 부록이 빈약해진다(WebRTC 스터디 교훈) |
| 미확인 사실 | 단정하지 말고 "문서마다 다르다(A: X, B: Y)" 또는 "확인 필요"로 표기, 출처 없는 수치는 "예시 값/가정"이라고 밝힌다 | |
| 문체 | 해라체(~이다, ~한다). 경어체 금지 | |
| 교차 링크 | 관련 포스트(`/posts/...`)·다른 스터디(`/study/...`)가 있으면 본문에 링크 | |

## 마크다운 함정 (빌드 실패·렌더링 깨짐)

| 패턴 | 문제 | 대신 |
|------|------|------|
| `<br/>` | Vue 컴파일 에러 | `<br>` |
| 코드 블록 밖 `{{ }}` | Vue 보간으로 해석돼 빌드 에러 | 인라인 코드/코드 블록으로 감싼다 |
| 본문의 `<태그>` 형태 텍스트 | HTML 태그로 해석 | 백틱으로 감싼다 |
| `**bold**한글` | 닫는 `**` 뒤에 한글이 붙으면 bold가 안 될 수 있다 | `<strong>bold</strong>한글` |
| `> [!TIP]` GitHub callout | 렌더링 안 됨 | `::: tip` |
| `- [ ]` 체크박스 | 이 블로그엔 task-list 플러그인이 없어 글자 그대로 보인다 | 일반 목록 |
| 절 사이 `---` | 스타일 규칙 위반 | `##` 제목만으로 구분 |
| ```` ```mermaid ```` | 새 콘텐츠는 matplotlib PNG로 통일 | `references/diagrams.md` |

`scripts/lint_study.py`가 위 항목 대부분을 자동으로 잡는다.

## 컨테이너

- `::: tip 제목` — 핵심 정리, 팁
- `::: info 제목` — 학습 목표, 참고 정보
- `::: warning 제목` — 주의사항, 운영 함정
- `::: details 제목` — 확인 문제, 긴 코드, 심화 내용
- `::: tabs` + `@tab 이름` — 여러 언어 코드 병기(예: Node.js / Spring)
