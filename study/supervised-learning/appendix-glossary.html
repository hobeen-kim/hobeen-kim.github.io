용어집

본문에 등장한 지도 학습 핵심 용어를 카테고리별로 한 줄씩 정리한다. 정확한 정의가 필요하면 scikit-learn User Guide와 각 라이브러리 공식 문서를 함께 참고한다. 기술 용어는 원문 표기를 유지한다.

기초

용어설명
지도 학습(Supervised Learning)입력 x와 정답 y의 쌍으로 이루어진 데이터에서 입력→출력 규칙을 학습해, 본 적 없는 입력의 출력을 예측하는 패러다임.
회귀(Regression)출력이 연속값인 예측 문제(예: 집값, 수요량).
분류(Classification)출력이 이산적인 범주인 예측 문제(예: 스팸 여부, 등급).
특징/피처(Feature)모델 입력을 이루는 개별 변수. 열(column) 하나가 보통 하나의 피처다.
레이블(Label)지도 학습이 맞혀야 할 정답값. 타깃(target)이라고도 한다.
일반화(Generalization)학습에 쓰지 않은 새로운 데이터에서도 성능을 유지하는 능력. 지도 학습의 궁극 목표다.
과적합(Overfitting)학습 데이터의 잡음까지 외워 train 성능은 높지만 일반화가 무너진 상태.
과소적합(Underfitting)모델이 너무 단순해 학습 데이터의 패턴조차 담지 못한 상태.
편향-분산 트레이드오프(Bias-Variance Tradeoff)모델의 체계적 오차(편향)와 데이터에 따른 흔들림(분산)이 서로 상충하며, 둘의 합으로 일반화 오차를 분해하는 관점.
편향(Bias)모델의 표현력 부족에서 오는 체계적 오차. 높으면 과소적합으로 이어진다.
분산(Variance)학습 데이터가 바뀔 때 예측이 흔들리는 정도. 높으면 과적합으로 이어진다.
잡음(Irreducible Error)데이터 자체에 내재한, 어떤 모델로도 줄일 수 없는 오차 하한.
데이터 누수(Data Leakage)학습 시점에 알 수 없어야 할 정보(테스트 정보, 미래 값 등)가 피처나 전처리에 새어 들어가 성능을 부풀리는 함정.
정규화(Regularization)모델 복잡도에 벌점을 주어 과적합을 억제하는 기법(L1, L2, 트리 깊이 제한 등).
하이퍼파라미터(Hyperparameter)학습으로 정해지지 않고 사람이 미리 지정하는 설정값(예: k, 학습률, 트리 개수).
표준화/스케일링(Standardization/Scaling)피처의 스케일을 맞추는 전처리. 거리·경사 기반 모델(kNN, 선형, SVM)에 특히 중요하다.
차원의 저주(Curse of Dimensionality)차원이 커질수록 점들 사이 거리가 균질해지고 데이터가 희박해져 거리 기반 방법이 무력해지는 현상.

평가

용어설명
정확도(Accuracy)전체 예측 중 맞힌 비율. 클래스가 불균형하면 오해를 부르는 지표다.
혼동 행렬(Confusion Matrix)실제-예측 조합을 TP·FP·FN·TN으로 집계한 표. 대부분의 분류 지표가 여기서 파생된다.
정밀도(Precision)양성으로 예측한 것 중 실제 양성 비율 TP/(TP+FP). 오탐 비용이 클 때 중요하다.
재현율(Recall)실제 양성 중 맞게 잡아낸 비율 TP/(TP+FN). 놓침(누락) 비용이 클 때 중요하다.
F1 점수(F1 Score)정밀도와 재현율의 조화평균. 둘의 균형을 하나의 수로 요약한다.
ROC 곡선(ROC Curve)임계값을 바꿔가며 TPR(재현율) 대 FPR을 그린 곡선.
ROC-AUCROC 곡선 아래 면적. 무작위로 뽑은 양성이 음성보다 높은 점수를 받을 확률과 같다. 불균형에는 낙관적으로 보일 수 있다.
PR 곡선(PR Curve)임계값에 따른 정밀도 대 재현율 곡선. 양성이 희귀한 불균형 문제에서 ROC보다 판별력이 높다.
PR-AUC / Average PrecisionPR 곡선 아래 면적. 희귀 양성 탐지 성능을 민감하게 반영한다.
임계값(Threshold)예측 확률을 양/음으로 가르는 경계값. 기본 0.5는 최적이 아닐 때가 많고 비용에 맞춰 조정한다.
MAE (Mean Absolute Error)오차 절댓값의 평균. 이상치에 상대적으로 둔감한 회귀 지표.
MSE / RMSE오차 제곱(의 제곱근) 평균. 큰 오차에 민감하며 RMSE는 타깃과 단위가 같다.
R² (결정계수)모델이 타깃 분산을 설명하는 비율. 1에 가까울수록 좋고 음수면 평균 예측만도 못하다.
로그 손실(Log Loss)예측 확률의 정확성을 벌하는 손실. 확률 품질을 볼 때 쓴다.
매크로/마이크로 평균(Macro/Micro Average)다중 클래스 지표를 클래스별 단순 평균(macro)하거나 샘플 전체로 집계(micro)하는 방식. 불균형에서 결과가 크게 갈린다.

모델

용어설명
kNN (k-Nearest Neighbors)예측 대상과 가장 가까운 k개 이웃의 다수결/평균으로 예측하는 게으른(lazy) 학습기.
거리 척도(Distance Metric)이웃을 정의하는 기준(유클리드, 맨해튼, 코사인 등). 스케일과 차원에 민감하다.
결정 경계(Decision Boundary)분류기가 클래스를 가르는 입력 공간상의 경계면.
OLS (Ordinary Least Squares)잔차 제곱합을 최소화하는 선형 회귀의 기본 해법.
릿지(Ridge, L2)계수 제곱합에 벌점을 주는 정규화. 계수를 0에 가깝게 줄이되 완전히 0으로 만들진 않는다.
라쏘(Lasso, L1)계수 절댓값에 벌점을 주는 정규화. 일부 계수를 정확히 0으로 만들어 변수 선택 효과를 낸다.
엘라스틱넷(Elastic Net)L1과 L2를 결합한 정규화. 상관된 피처가 많을 때 라쏘의 불안정성을 보완한다.
로지스틱 회귀(Logistic Regression)선형 결합을 시그모이드/소프트맥스로 확률에 매핑해 분류하는 모델.
시그모이드(Sigmoid)실수를 0~1 사이 확률로 압착하는 함수. 이진 로지스틱 회귀의 출력 함수.
소프트맥스(Softmax)여러 점수를 합이 1인 확률 분포로 변환하는 함수. 다중 클래스 분류에 쓴다.
SVM (Support Vector Machine)두 클래스 사이 마진을 최대화하는 결정 경계를 찾는 모델.
서포트 벡터(Support Vector)마진 경계 위에 놓여 결정 경계를 실제로 결정하는 데이터 점들.
커널 트릭(Kernel Trick)데이터를 고차원으로 명시적으로 옮기지 않고 내적만으로 비선형 경계를 얻는 기법.
나이브 베이즈(Naive Bayes)피처 간 조건부 독립을 가정하고 베이즈 정리로 클래스 확률을 계산하는 확률 분류기.
결정 트리(Decision Tree)피처 기준의 예/아니오 분기를 반복해 예측하는 규칙 기반 모델.
불순도(Impurity)노드 안 클래스가 섞인 정도. 지니(Gini)·엔트로피로 재고 이를 줄이는 분할을 고른다.
정보 이득(Information Gain)분할 전후 불순도 감소량. 트리가 분할 기준을 고르는 척도.
잔차(Residual)실제값과 예측값의 차이. 부스팅은 이 잔차(정확히는 손실의 그래디언트)를 순차적으로 학습한다.
가지치기(Pruning)과하게 자란 트리의 가지를 잘라 복잡도를 낮추는 과적합 제어.

앙상블

용어설명
앙상블(Ensemble)여러 약한 모델을 결합해 하나의 강한 예측기를 만드는 기법.
배깅(Bagging)부트스트랩 표본으로 여러 모델을 병렬 학습해 평균/투표로 합치는 방법. 주로 분산을 줄인다.
부스팅(Boosting)이전 모델의 오차를 다음 모델이 순차적으로 보정하며 쌓는 방법. 주로 편향을 줄인다.
스태킹(Stacking)서로 다른 모델의 예측을 메타 모델의 입력으로 다시 학습시키는 결합 방식.
부트스트랩(Bootstrap)원본에서 복원 추출로 같은 크기의 표본을 여러 벌 만드는 리샘플링.
OOB (Out-of-Bag)부트스트랩에 뽑히지 않은 샘플. 별도 검증셋 없이 랜덤 포레스트를 평가하는 데 쓴다.
랜덤 포레스트(Random Forest)배깅에 피처 무작위 선택을 더해 트리 간 상관을 낮춘 대표적 배깅 앙상블.
피처 무작위성(Feature Randomness)각 분할에서 전체가 아닌 일부 피처만 후보로 삼아 트리들을 서로 다르게 만드는 장치.
GBDT (Gradient Boosted Decision Trees)결정 트리를 약한 학습기로 쓰는 그래디언트 부스팅. tabular 예측의 사실상 표준.
학습률(Learning Rate, eta)각 트리의 기여를 축소하는 계수. 작을수록 일반화가 좋아지지만 더 많은 트리가 필요하다.
트리 개수(n_estimators)부스팅이 순차적으로 쌓는 트리의 수. 학습률과 함께 조절한다.
Early Stopping검증 지표가 일정 라운드 동안 나아지지 않으면 학습을 멈춰 최적 트리 수를 자동으로 찾는 기법.
2차 근사(Second-order Approximation)손실을 그래디언트와 헤시안까지 테일러 전개해 분할 이득을 계산하는 XGBoost의 핵심.
히스토그램 분할(Histogram-based Split)연속값을 버킷(bin)으로 이산화해 분할 후보를 줄여 학습을 가속하는 기법. LightGBM·XGBoost hist가 사용.
Leaf-wise 성장손실이 가장 크게 줄어드는 리프를 우선 키우는 LightGBM의 트리 성장 전략. 깊고 불균형한 트리가 되기 쉬워 규제가 필요하다.
GOSS (Gradient-based One-Side Sampling)그래디언트가 큰 샘플은 남기고 작은 샘플은 표본화해 속도를 올리는 LightGBM 기법.
EFB (Exclusive Feature Bundling)동시에 0이 아닌 경우가 드문 희소 피처들을 하나로 묶어 차원을 줄이는 LightGBM 기법.
Ordered Boosting타깃 누수를 막기 위해 각 샘플의 통계를 그 샘플 이전 데이터로만 계산하는 CatBoost의 학습 방식.
타깃 인코딩(Target Encoding)범주형 값을 해당 범주의 타깃 통계로 치환하는 인코딩. CatBoost가 누수를 막아 내장 처리한다.

실전

용어설명
피처 엔지니어링(Feature Engineering)원 데이터를 모델이 학습하기 좋은 피처로 가공·생성하는 작업.
원-핫 인코딩(One-Hot Encoding)범주형 변수를 범주 수만큼의 0/1 열로 펼치는 인코딩.
순서형 인코딩(Ordinal Encoding)범주를 정수로 매핑하는 인코딩. 순서가 있거나 트리 모델에 쓸 때 적합하다.
결측치 대치(Imputation)비어 있는 값을 평균·중앙값·모델 예측 등으로 채우는 전처리.
파이프라인(Pipeline)전처리와 모델을 하나의 객체로 묶어 학습/예측 시 같은 순서로 적용하는 sklearn 구조. leakage 방지의 핵심.
ColumnTransformer수치·범주 열마다 다른 전처리를 병렬로 적용해 하나로 합치는 sklearn 컴포넌트.
교차 검증(Cross-Validation)데이터를 여러 fold로 나눠 번갈아 학습·검증하며 성능을 안정적으로 추정하는 방법.
StratifiedKFold각 fold의 클래스 비율을 원본과 같게 유지하는 분할. 불균형 분류에 기본으로 쓴다.
GroupKFold같은 그룹(사용자·기기 등)이 train과 valid에 동시에 들어가지 않게 나누는 분할. 그룹 누수를 막는다.
TimeSeriesSplit과거로 학습하고 미래로 검증하도록 시간 순서를 지키는 분할. 시계열 누수를 막는다.
클래스 가중치(Class Weight)손실에서 소수 클래스의 오차에 더 큰 비중을 주어 불균형을 보정하는 방법.
리샘플링(Resampling)소수 클래스를 늘리거나(oversampling, SMOTE) 다수 클래스를 줄여(undersampling) 균형을 맞추는 기법.
SMOTE소수 클래스 샘플 사이를 보간해 합성 샘플을 생성하는 오버샘플링 기법.
캘리브레이션(Calibration)모델이 내놓는 확률을 실제 관측 빈도에 맞게 보정하는 것(Platt scaling, isotonic).
신뢰도 곡선(Reliability Diagram)예측 확률 구간별 실제 양성 비율을 그려 캘리브레이션 상태를 진단하는 그래프.
피처 중요도(Feature Importance)각 피처가 예측에 기여한 정도. 트리의 분할 기반 중요도는 고카디널리티 피처에 편향될 수 있다.
Permutation Importance한 피처의 값을 무작위로 섞었을 때 성능이 얼마나 떨어지는지로 중요도를 재는, 모델 불문 방식.
SHAP (SHapley Additive exPlanations)게임 이론의 Shapley 값으로 각 피처가 개별 예측에 기여한 몫을 일관되게 분해하는 해석 기법.
PDP (Partial Dependence Plot)한두 피처를 바꿀 때 예측이 평균적으로 어떻게 변하는지 보여주는 그래프.
베이스라인(Baseline)성능을 견줄 최소 기준 모델(다수 클래스 예측, 평균 예측 등). 개선 여부 판단의 출발점.

scikit-learn 치트시트에서는 여기 정리한 개념이 실제 API 호출로 어떻게 쓰이는지 이어서 다룬다.
