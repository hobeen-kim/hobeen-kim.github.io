DDI 주요 목록

처음 읽는다면

이 부록은 TC(Task Controller, 작업을 기록하고 제어하는 장치)가 주고받는 값의 종류 번호인 DDI를 찾아보는 목록이다. 처음부터 읽는 글이 아니라, 본문이나 DDOP에서 모르는 DDI 번호를 만났을 때 펼쳐 본다. DDI가 처음이라면 45장 TC 프로세스 데이터 기초를 먼저 읽는다.

DDI(Data Dictionary Identifier)는 ISO 11783-11이 규정하는 2바이트(16비트) 식별자로, Task Controller가 작업기의 측정값이나 설정값의 종류를 식별하는 데 사용한다. 개별 DDI 항목은 표준 문서 본문에 실려 있지 않고, ISO가 지명한 유지관리 기관(VDMA)이 관리하는 isobus.net의 ISOBUS Data Dictionary(온라인 사전 자체가 normative reference)에 정의된다. DDOP(Device Descriptor Object Pool) 안의 DPD(Device Process Data)·DPT(Device Property) 오브젝트에서 참조된다.

확인 근거

DDI 6은 ISO 11783-10의 ISOXML 예시 문장에서 값과 함께 직접 확인했다. 개별 DDI의 이름·단위·분해능은 Part 10/11 본문에 없고 isobus.net Data Dictionary가 관리한다. DDI 1·2·3의 이름과 단위(mm³/m²), DDI 1의 분해능 0.01은 그 사전에서 확인했다(2026-10 기준). 대유량(분뇨 살포 등)용으로 ml/m² 단위를 쓰는 별도 DDI(588 Setpoint, 589 Actual, 591 Maximum, 592 Default)가 따로 있으니 DDI 1과 혼동하지 않는다.

혼동하기 쉬운 번호

이 표는 예전에 시간당 유량을 16·17, 시간당 질량을 21·22로 적었으나 isobus.net Data Dictionary로 확인한 결과 틀린 번호였다. 16·17은 Setpoint·Actual Spacing Application Rate(간격, mm)이고, 21·22는 Volume Per Volume Application Rate(mm³/m³)다. ISO 11783-10이 파종기(Seeders/Planters)의 권장 rate DDI로 16·17을 드는 것도 파종 간격이기 때문이다. 45장 TC 프로세스 데이터 기초의 36·37(mm³/s)이 맞다.

DDI 값 표현 방식

DDI 값은 모두 부호 있는 32비트 정수(int32, −2³¹~2³¹−1)로 전송된다. 실제 단위 값으로 변환하려면 DDI별 해상도(Resolution)를 적용해야 한다.

예시:

  • DDI 1 (Setpoint Volume Per Area): 1 bit = 0.01 mm³/m² (1 L/ha = 원시값 10 000)
  • DDI 67 (Actual Working Width): 1 bit = 1 mm
  • DDI 271 (Lifetime Total Area): 1 bit = 1 m²

위 해상도 수치는 예시이며, 각 DDI의 공식 해상도·값 범위는 isobus.net의 ISOBUS Data Dictionary에서 확인해야 한다.

근거: ISO 11783-10 D.41(ProcessDataValue 범위), B.3

DDI 1 분해능의 근거

DDI 1의 단위 mm³/m²와 분해능 0.01은 isobus.net Data Dictionary 항목에서 확인했다(CAN 범위 0~2 147 483 647, 표시 범위 0.00~21 474 836.47). 45장 TC 프로세스 데이터 기초의 계산(1 L/ha = 원시값 10 000)과 일치한다.

참고

  • DDI 전체 목록은 AEF 공개 문서 및 ISO 11783-11 Data Dictionary에서 확인할 수 있다.
  • isobus.net에서 DDI 검색 도구를 제공한다.
